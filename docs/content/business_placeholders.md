# Business Placeholders

## Purpose

This file stores temporary placeholder business content for the first website release.

Its purpose is to prevent missing client inputs from blocking implementation.
All placeholders in this file are intentionally obvious and must be easy to search and replace later.

## Placeholder rules

Use these rules everywhere in the codebase and docs:

- Every unknown business value should use a clear placeholder token.
- Prefer uppercase placeholder tokens with a `TODO_` prefix.
- Do not invent realistic business facts unless needed for layout testing.
- If a realistic-looking dummy value is needed for rendering, keep the `TODO_` marker visible in the string.
- If content is completely unknown, keep it short and neutral rather than making up detailed marketing claims.
